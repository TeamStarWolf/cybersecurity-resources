# Security Policy

This repository is a catalog of links: data files, the scripts that check and build them, and the pages and bookmark files they generate. It runs no service and has no user accounts. What can go wrong here is a link that is wrong or now leads somewhere it should not, a generated file that carries something it should not, or a fault in a script or workflow.

## What to report, and how

| You found | Report it through |
|---|---|
| A wrong description, cost, publisher or status | A [public issue](https://github.com/TeamStarWolf/cybersecurity-resources/issues) or a pull request |
| A broken link, or a link that now leads somewhere it should not, such as a lapsed domain or a page replaced by something unrelated | A [public issue](https://github.com/TeamStarWolf/cybersecurity-resources/issues). Say so in the title if the destination looks harmful |
| A vulnerability in a script under `scripts/` or a workflow under `.github/workflows/`, or anything else you would rather not disclose in public | The contact published in [teamstarwolf.com/.well-known/security.txt](https://teamstarwolf.com/.well-known/security.txt) |

Please do not open a public issue for anything sensitive. In a private report, say which file or address it concerns, what you found and how to reproduce it.

## Scope

- In scope: the data under `data/`, the scripts under `scripts/`, the workflows under `.github/workflows/`, and the generated pages and bookmark files.
- Out of scope: the sites, tools and services this catalog links to. They belong to their operators; report a problem with one of them to its owner.

## Response

This is a volunteer, community-maintained project with no formal SLA. Reports are reviewed on a best-effort basis.
