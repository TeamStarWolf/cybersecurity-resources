# Cybersecurity Resources

A curated, **vulnerability-management- and threat-intelligence-first** collection of 292 cybersecurity bookmarks, organized into a detailed folder structure you can import into any browser.

Covers CVE/vuln databases, exploit prediction and prioritization (KEV / EPSS / CVSS / SSVC), a deep **vendor advisory / PSIRT** section, threat intelligence feeds and CTI research, government/CERT alerts, frameworks and standards (MITRE, NIST, CIS, OWASP), offensive and DFIR tooling, cloud and container security, detection engineering, labs, and news.

## Contents

- **`bookmarks.html`** — import this into your browser to get the whole folder tree.
- **`LINKS.md`** — the same links as a browsable Markdown list.

## Import (Chrome / Edge / Brave)

1. Open `chrome://bookmarks` → **⋮** → **Import bookmarks**.
2. Choose **Bookmarks HTML File** and select `bookmarks.html`.
3. The links land under an **Imported** folder; drag the **Cybersecurity Resources** folder onto your Bookmarks Bar.

## Import (Firefox)

**Bookmarks → Manage Bookmarks → Import and Backup → Import Bookmarks from HTML**, then pick `bookmarks.html`.
